01 / CONFIGURATION

Secure setup

In Sites Settings

Credentials belong in the site’s server environment. This page shows whether they are configured; it never receives or saves their values.

  1. Open the site’s settings

    In ChatGPT → Sites → Telvyo → More actions → Settings, open the environment variables / secrets section.

    Open Sites settings ↗
  2. Add the configuration below

    Use the exact, case-sensitive variable names. Mark every credential as a secret in the hosting settings.

  3. Apply and refresh

    Save or apply your changes in Sites Settings and redeploy if prompted. Return here and choose Refresh status, then run an available authentication check.
